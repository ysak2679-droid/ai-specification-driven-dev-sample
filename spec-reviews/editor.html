仕様書確認一覧エディタ

spec-reviews フォルダの確認一覧（例：SCR-01_qa.md）をここにドラッグ＆ドロップ
または「ファイルを開く」から選択（Ctrl を押しながら選ぶと複数まとめて開けます）
使い方
  1. 確認一覧の md を開く。
  2. 修正内容 を入力する（修正状態は自動で「修正済AI未確認」になる）。
  3. 「保存（ダウンロード）」を押す → 作り直した md がダウンロードされる。
  4. ダウンロードした md を spec-reviews フォルダの同名ファイルに上書きする。
  5. Claude Code で /check-spec を実行する → AI が AI確認OK／AI確認NG を付ける。
ヒント：ブラウザの設定で「ダウンロード時に保存場所を毎回確認する」をオンにすると、保存時に spec-reviews を選んで直接上書きできます。
