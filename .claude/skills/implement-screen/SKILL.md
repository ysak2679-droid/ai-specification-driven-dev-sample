# 画面実装手順：$ARGUMENTS

次の手順を順番に実行する。

1. **仕様を読む**
   `specs/` から `$ARGUMENTS` で始まる PNG を開き、画像を読み取る。
2. **不備を確認し、項目を書き出す**
   - `/check-spec $ARGUMENTS` を実行し、`spec-reviews/` の確認一覧を最新にする。
   - 項目定義表の No / 項目 / 種別 / 仕様 を一覧にしてユーザーに示す。`AI確認OK` の「修正内容」は仕様書の付属情報として一覧に含める。
   - 重大度エラーに `AI確認OK` でない行があれば、その行を示し「エラーの項目が修正されていません。本当に修正しますか？」と伝える。
     確認はハーネス（`app/` への書き込み時の確認ダイアログ）が行う。ユーザーが拒否したら実装を止める。
3. **部品を決める**
   `.claude/rules/material-design.md` の「種別 → コンポーネント対応表」で各項目の部品を決め、一覧に追記する。
4. **実装する**
   - `app/styles/tokens.css` が無ければ、ルールに書かれたトークンで先に作る。
   - `app/<仕様書のファイル名>.html` を作成する（例：`app/SCR-01_qa.html`）。
   - 振る舞い（活性条件・入力チェック・遷移）は仕様の文言どおりに JavaScript で実装する。
5. **照合する**
   項目一覧の全行について「実装済み / 対象外」を表で報告する。仕様に無い要素を追加していないことも確認する。
